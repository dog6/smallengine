### Uses:
```
- SFML    -- 2D Rendering
- Box2D   -- 2D Physics/Collision Solver
- sol2    -- Binding to Lua
- TOML    -- Settings/Config files in TOML
- spdlog  -- Logging
```

### Tips:
```
  - KISS  -- Keep It Stupid Simple (we'll see about this one)
  - YAGNI -- You Aren't Going To Need It (don't implement what isn't needed strictly speaking)
  - DRY   -- Don't Repeat Yourself (if it's done 3 times, it should probably have a function)
  - IWYU  -- Include What You Use 
```
### Goal:
  Create a lightweight C++ 2D game engine that I can use to at least make a few games.
  Complete the project MVP
  
  Really nothing crazy, but a 2D engine that has a good foundation to be built on-top of that
  can serve as a project I can fiddle with when I want to practice C++
